# Security policy

## Supported versions

Security fixes are provided for the latest published native release. Users
should upgrade to the newest AppImage before reporting a problem.

## Reporting a vulnerability

Do not open a public issue for a vulnerability involving arbitrary code
execution, unsafe input injection, path traversal, credential or cookie
exposure, update integrity, or local-network access.

Use GitHub's **Security → Report a vulnerability** flow to submit a private
security advisory. Include:

- affected version;
- distribution, Plasma, Qt, and Wayland/XWayland details;
- exact reproduction steps;
- impact and attack prerequisites;
- a minimal proof of concept when safe;
- any proposed mitigation.

Do not include live account credentials, session cookies, personal whispers,
or private game logs. You should receive an acknowledgement when the
repository owner is available, but no response-time guarantee is offered. This
project is maintained with AI assistance because the owner does not have time
to maintain it alone, and the software is provided as-is.
